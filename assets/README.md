# Assets

| Path | What it is |
| --- | --- |
| `brand/icon.svg` | The source of the app icon: a tree whose trunk and boughs are git branches, with the newest commit on each branch as amber fruit. |
| `icon.png` | The icon rendered at 1024×1024, used by the Giode CLI for every platform's app icon and by the window. |
| `brand/icon-256.png` | The small logo shown in the sidebar and title bar. |
| `icons/` | UI glyphs, 24×24 stroke SVGs that follow the text colour. Each file name is the glyph's name. |
| `fonts/` | Inter and JetBrains Mono, with their licenses. |

To change the icon, edit `brand/icon.svg` and render both PNGs from it at 1024 and 256 pixels.
